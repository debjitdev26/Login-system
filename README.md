# Login System

A MERN authentication system featuring:

- JWT Authentication
- Refresh Token Rotation
- Email Verification with OTP
- Password Reset via OTP
- Session Management
- Cloudflare Turnstile Bot Protection
- Rate Limiting
- Logout from All Devices

## Tech Stack

- React
- Node.js
- Express.js
- MongoDB
- JWT
- Cloudflare Turnstile
